# Feature Pruning & Utility (Zéro-Gadget & Moins de Couches)

## Principes
1. **Zéro Écran Inutile** : Réduire le nombre de clics pour postuler (1-clic pour matcher, adapter et exporter).
2. **Clarté Visuelle Maximale** : Afficher immédiatement la valeur ajoutée (diff visuel clair entre version originale et version adaptée).
3. **Zéro Dépendance Lourde Injustifiée** : Privilégier les calculs mathématiques purs et le CSS natif pour une réactivité instantanée.
