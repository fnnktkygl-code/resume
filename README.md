# Resume Builder

This project is a React-based web application for building professional resumes. 
It supports multiple templates, rich text editing, and AI-assisted profile completion.

## Live Application

The application is deployed on Vercel. You can access it here:

**🔗 [Resume Builder Web App](https://resume-teal-omega.vercel.app/)**

*(Production URL: https://resume-pbvod9uus-httpsgithubcomfnnktkygl-coderesume.vercel.app)*

## Development

```bash
npm install
npm run dev
```

## Features
- Multiple beautiful templates (Minimalist, Modern, Creative, ATS-optimized)
- Multi-page support
- Local storage saving
- PDF export
- Full real-time preview
